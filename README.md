# Correção de erros do windows 
  Um único arquivo .bat que irá mudar a forma como você soluciona problemas do Windows.

## *Este é sem duvida o Script mais completo que tem para melhorias do Windows*

### Suas principais funções:

- Solução de problemas e melhoria na rede
-  Solução de problema com impressora
-  Remoção de softwares desnecessários
-  Correção de segurança desativando o SMB1 (Protocolo de conexão vulnerável a ataques)
-  Melhoria de desempenho desativando o HPET (Melhora o desempenho em computadores mais simples)
-  Desativar a função de vincular celular
-  desativar a pesquisa do bing no menu iniciar
-  Remover programas inuteis
-  Ativar o controle de brilho do monitor pelo Windows
-  Remover o Copilot do Windows e do Egde
-  Desativar o OneDrive e remover todos as pastas relacionadas
-  Limpeza dos arquivos temporários incluindo antigas atualizaçãoes do Sistema
-  Desativar Widgets do Windows
-  Reparar icones corrompidos
-  Reparar arquivos corrompidos do sistema
-  Realizar teste de conexão
-  ativar o GodMode (Modo deus), uma pasta com todas as configurações do sistema
-  E muito mais, ao todos são 21 funções e no futuro será implementado mais.

## Funções secundárias
.
Algumas funções pedem para o computador ser reíniciado após a aplicação, caso isso seja necessário, será perguntado ao usuário se ele deseja reiniciar naquele momento ou não.<br>
<br>
O programa conta com dois menus por conta da quantidade de ferramentas disponíveis, para avançar nos menus aperte [D] depois [ENTER] e para voltar [A] depois [ENTER].<br><br>
À Algumas funções que podem ser ativadas e desativadas, quando ouver essa opção, será perguntado ao usuário o que ele deseja, Ativar ou Desativar, com o respectivo comando para cada um.
